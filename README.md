# ⚛️ Conversor de Unidades al Sistema Internacional (SI)

Aplicación de escritorio desarrollada en **Python** con interfaz gráfica (`tkinter`) para la asignatura **Informática y Programación** del Grado en Física (UNIR).

El proyecto ha sido construido aplicando una metodología de desarrollo iterativo asistido por inteligencia artificial (*vibe coding*) mediante **GitHub Copilot** en **Visual Studio Code**.

---

## 🚀 Funcionalidades principales

* **Conversión de magnitudes físicas:**
  * Energía: Calorías (`cal`) $\rightarrow$ Julios (`J`)
  * Presión: Atmósferas (`atm`) $\rightarrow$ Pascales (`Pa`)
  * Velocidad: Kilómetros por hora (`km/h`) $\rightarrow$ Metros por segundo (`m/s`)
  * Temperatura: Grados Celsius (`°C`) $\rightarrow$ Kelvin (`K`) y grados Fahrenheit (`°F`)
* **Enfoque didáctico:** Muestra la fórmula o factor de conversión aplicado debajo de cada resultado.
* **Validación de entrada:** Control de errores mediante ventanas emergentes ante valores no numéricos y soporte para decimales con punto o coma.
* **Usabilidad:** Permite ejecutar el cálculo tanto pulsando el botón como con la tecla `Enter`.
